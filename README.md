# homebrew-tap

Homebrew casks by akito8639.

```bash
brew tap akito8639/tap
brew install --cask orbit-for-claude-code
```

| Cask | What |
|---|---|
| `orbit-for-claude-code` | [Orbit for Claude Code](https://github.com/akito8639/orbit-for-claude-code) — menu bar app + widgets for Claude Code usage limits, sessions and status (macOS 26+) |
